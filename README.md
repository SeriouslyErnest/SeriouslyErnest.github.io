# Seriously Ernest

A small collection of things I have built while experimenting with product ideas, workflows and AI-assisted development.

I tend to start with a practical problem, work out how I think the experience should behave, and then build enough of it to test whether the idea actually works.

## Projects

### BusGlance
A simple way to compare the buses I care about across nearby bus stops, so I can decide which way to head at a glance.

- Live demo: https://BusGlance.lovable.app/demo
- Repository: https://github.com/SeriouslyErnest/BusGlance

### HomeStock
Know what you have. Buy what you need.

A household inventory and restocking tool designed to make it easier to keep track of everyday items without turning inventory management into another chore.

- Status: Coming soon / Private beta
- Repository: https://github.com/SeriouslyErnest/homestock-helper

### CommonRoute
A collaborative trip-planning tool for groups with different preferences, priorities and pacing.

- Status: Coming soon / Public beta
- Repository: https://github.com/SeriouslyErnest/commonroute
